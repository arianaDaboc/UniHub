# UniHub

UniHub is a full-stack academic workspace that centralises courses, assignments, deadlines, materials, schedules and notifications.

## Technology

- React and TypeScript
- Java 17 and Spring Boot
- Spring Security with JWT and role-based authorisation
- PostgreSQL, Spring Data JPA and Flyway
- Spring Mail with Mailpit for local email capture
- JUnit 5, Mockito and H2

## Roles

- **Student:** course enrolment, assignment progress, materials, calendar, schedule, reviews and notifications.
- **Professor:** course creation, assignments, PDF materials, prerequisites, schedules and enrolled-student management.
- **Administrator:** user roles and complete academic catalogue management.

## Highlights

UniHub includes deadline priority classification, institutional-email registration, course ownership checks, prerequisite validation, ICS calendar export, co-enrolment recommendations, in-app notifications and deduplicated deadline reminders captured in Mailpit.

Detailed architecture, data modelling and role documentation is available in [the technical PDF](docs/UniHub-Technical-Documentation.pdf).
